Primeira versão do MemoRadar.

- Memória e pressão na barra de menu, com o ícone mudando de cor.
- Ranking de apps, projetos do VS Code, sessões do Claude Code no terminal e MCPs abertos.
- Aviso de projetos esquecidos, depois de 4 horas parados, por padrão. O aviso aparece com o nome do Editor de Script, porque a API oficial recusa apps sem certificado pago da Apple.
- Fechar pelo app, sempre com confirmação.

**Para instalar**, abra o `.dmg` e arraste o MemoRadar para a pasta Aplicativos.

**Na primeira abertura**, o macOS avisa que não consegue verificar o desenvolvedor. Abra Ajustes do Sistema > Privacidade e Segurança e clique em Abrir Mesmo Assim. O README explica o motivo.
